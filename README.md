# VitePress Tutorial

A simplified introduction to [VitePress](https://vitepress.dev) for beginners, built as a live demo for the course B5.4.3 – Component-Based Development.

**[Check it out](https://vitepress-tutorial-inky.vercel.app/)**

## What it covers

- **Getting started:** installation, the setup wizard, file structure and configuration
- **Routing:** file-based routing, linking between pages, clean URLs, route rewrites and dynamic routes
- **Markdown features:** custom containers, alerts, code groups and syntax highlighting

## What I did

- Built the site and organised the content into a short learning path
- Designed the home page to link each VitePress feature to its explanation
- Added a custom `success` container using a markdown-it plugin and CSS
- Deployed the site on Vercel

Credit where it's due: the tutorial content is adapted from the [official VitePress documentation](https://vitepress.dev).

## Tech stack

VitePress · Vue · Vite · Markdown · TypeScript · Vercel

## Run locally

Requires Node.js 20 or later.

```sh
npm install
npm run docs:dev
```

Then open <http://localhost:5173>.
